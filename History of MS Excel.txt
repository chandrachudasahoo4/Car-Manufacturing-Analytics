History of MS Excel----

Software : MS Excel
Developed by : Microsoft
Chief Architect : Doug Klunder
First released : 1985
First platform : MAC
first windows version : 1987(Excel 2.0)


Evolution of MS Excel:---->

1985 – First Release:* Microsoft launched Excel for Apple Macintosh as a spreadsheet program designed to compete with Lotus 1-2-3.
1987 – Windows Version:* Excel 2.0 became the first Windows spreadsheet featuring a graphical interface, which helped popularize Excel on PCs.
Early 1990s – Growth Phase:* Excel started gaining dominance due to its easy charts, formulas, and automation features.
1993 – Excel 5.0:* Introduced VBA (Visual Basic for Applications), allowing user to automating task with macros.
1995 - Office Integration : Excel become the part of the Microsoft office, boosting the adaption in businesses and education.
2003 - Mature Classic Era : Excel 2003 represent the peak of classic menu interface used many years.
2007 - Major Redesign : Excel introduced the ribbon interface and expanded worksheet size.
2010-2016 - Advance feature : Added power pivot . power query better charts , and data analysis tools for business intelligence.
2019-Present : Could & AI : Excel introduced with Microsoft 365 , enabling real-time collaboration , cloud storage , dynamic arrays & AI-powered insights.
Today : Excel is one of the most widely used spreadsheet tools world wide for data analysis , accounting , research and business reporting.


Why Excel ? :----------------
It is called excel because Microsoft wanted a name showed the software helps user excel (do very well / perform better) at calculation, data handling and analysis.

Work Book : It is the excel file present in our system with the extension ".xlsx" .
Work Sheet : These are the sheets where we store some data which is present inside a workbook.
 

Cell Referencing:---------->
It means using a cell address inside a formula.

Types of cell reference:
    It is of 3 types:
	1. Relative Reference
	2. Absolute Reference
	3. Mixed Reference


1. Relative Reference: It changes automatically once the formula is copied.
2. Absolute Reference: It will keep the formula fixed even after copy.
 


Some Basic Error in Excel :
	1. #VALUE! Error : It occur when wrong data type is given.
	2. #DIV/0! Error : It occur when the formula divided is zero .
	3. #NAME? Error : It occurs when excel doesn't recognize the formula of the function name .
	4. #REF! Error: It occurs when an invalid cell reference is used in a formula.
	5. #N/A Error (Not Available): It occurs when a value is not available or Excel cannot find the required data.
